# 루티 기록 편집 웹 체험

결과 화면의 **앱 편집 체험하기**에서 진입한다. 산행으로 만든 실제 체험 기록과 편집 데모는 별도 상태를 사용한다. 데모의 기본 사진·수치는 제공된 Figma의 샘플이다.

## Figma 화면 대응

파일: `34LtxSTw13SrZZfpz1FfCM`

| 노드 | 구현 상태 |
| --- | --- |
| 12426:34123 | 배경 사진 변경 후 도구 선택 해제, 변경 내용 초기화 |
| 12426:34211 | 배경 어둡기 슬라이더 |
| 12426:33924 | 사진 타임라인 + 8색 팔레트 |
| 12426:34338 | 루트명 + 8색 팔레트 |

색상은 한 상태값에서 수치, 경로, 사진 테두리, 루트명, 루트 핀에 적용된다. 도구 탭과 관계없이 캔버스의 스티커를 바로 선택·이동·확대/축소·삭제할 수 있다. 다른 도구를 열면 선택을 해제하고, 밝기바를 조작하는 동안에는 선택 프레임을 숨긴다. 스티커는 유형별로 하나씩 사용한다. 이미 있는 유형을 누르면 위치와 크기를 유지하며 해당 스티커를 선택하고, 삭제한 유형은 다시 추가한다. 밝기 조작 중에는 스티커 선택 프레임을 표시하지 않는다.

기기 사진 선택은 브라우저 로컬 Blob URL을 사용하며 서버로 업로드하지 않는다. 공유 API를 지원하는 기기는 공유창을 열고, 지원하지 않으면 PNG 저장으로 연결한다.

## 구현 및 검증

- `dist/editor-model.js`: 편집 상태와 규칙
- `dist/editor.js`: 도구·드래그·크기·핀치·PNG 렌더·완료 흐름
- `dist/editor.css`: Figma의 375×812 좌표와 원본 자산 배치
- `dist/assets/editor/`: Figma MCP로 받은 자산 및 Archivo 글꼴
- `tests/editor-model.test.cjs`: 색상 유지, 유형별 중복 방지, 모든 탭에서 직접 선택, 완료 후 잠금, 삭제/재추가, 밝기 범위

실제 브라우저에서 배경 사진 교체, 드래그, 크기 조절, 밝기, 8색 적용, 전체 삭제·재추가, 탭 간 상태 유지, 완료 전환 및 1029×1830 PNG 저장을 확인했다. 공유는 브라우저/기기의 공유 지원에 따라 분기한다.
