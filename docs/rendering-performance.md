# 산행 렌더링 성능 개선

- 고정 월드 지형의 높이·색상은 행 단위로 재사용하며 화면에 보이는 구간만 보관한다.
- 카메라의 위치·삼각함수는 프레임당 한 번 계산하고 화면 밖 나무·바위는 그리지 않는다.
- 지형과 길의 분할 수를 낮추고, 최대 60fps로 갱신한다.
- 캔버스는 최대 약 140만 픽셀로 제한한다. 렌더링 계산이 지속적으로 무거우면 해상도를 단계적으로 낮춘다.
- 수치 HUD는 초당 최대 10회 확인하고, 값이 달라졌을 때만 텍스트를 바꾼다. 움직이는 배경 위의 실시간 흐림 효과를 제거한다.
- 자동 배경 수집은 동기 JPEG 문자열 변환 대신 비동기 Blob으로 저장한다. 최대 12개만 유지하고 재시작 시 해제한다.
- 결과/편집 화면과 숨긴 탭에서는 산행 캔버스 렌더링을 멈춘다. 결과 진입 시 발소리 상태도 즉시 전환한다.

## 검증

동일 데스크톱 브라우저의 120Hz 환경에서 로컬 검증 화면으로 비교했다. 수정 전 RAF 콜백 평균 작업은 약 2.5ms, 최적화 후 약 0.6ms였다. 이 수치는 해당 환경의 JavaScript 처리 시간이며 전체 기기의 FPS나 GPU 부하를 보장하지 않는다. 결과 화면에서는 산행 캔버스 다시 그리기 0회와 콜백 평균 약 0ms를 확인했다. 촬영·경로 선택·인칭 전환·기록 완료를 브라우저에서 확인했다.

공개 사이트 반영은 사용자의 2026-11-05 지시에 따라 이후 수정에도 기본으로 수행한다. 기존 배포 브랜치를 사용하고 main에는 머지하지 않는다.

## 카메라 근거리 지형 유지

카메라 가까운 경계(깊이 45)를 삼각형의 꼭짓점 하나만 넘어도 전체 면을 버리던 처리를 수정했다. 경계에 걸친 면은 카메라 좌표에서 잘라 남은 면을 그린다. 화면 아래로 꼭짓점 하나만 내려가도 타일을 버리던 조건도 전체 면이 화면 밖일 때만 제외하도록 수정했다. 지면과 길의 가까운 범위는 현재 위치 뒤 450까지 이어진다.

`tests/trail-geometry.test.cjs`로 경계 교차 시 삼각형/사각형 유지, 전체 후방 면 제외, 2D 도형 유지를 검증한다. 브라우저에서 숲·능선 방향 전환과 정상 접근의 1/3인칭 지면을 확인했다.

기록 중 수치는 거리(km)·시간·최고 고도(m)를 가운데 정렬하고 시간은 HH:MM으로 표시한다. 완료 기록의 h/m 표시는 유지한다.
