# 루티 정상까지 이어지는 산행 코스

## 산행 흐름

- 월드 전진 좌표 9,000마다 정상에 도착하는 반복 코스. 기본 걷기는 약 2분, 빠른 뛰기는 약 1분 내외이며 자유 이동 방향에 따라 더 걸릴 수 있다. 하단 속도 바에서 60~185 사이의 월드 속도를 조절하고 걷기(75)·뛰기(175) 프리셋을 선택할 수 있다.
- 갈림길 3개: 700, 3,300, 5,900. 숲길은 왼쪽, 능선은 오른쪽으로 이어지고 각 구간 끝에서 합류한다.
- 경로 선택은 실제 가지 경로를 따라 자동으로 방향을 조정한다. 클릭·탭·방향키로 언제든 자유 탐험으로 전환할 수 있다.
- 숲/능선 환경은 월드 좌표에 배치한다. 메뉴 선택 여부와 관계없이 반대쪽 지형으로 걸어가면 해당 환경이 나타난다.
- 숲: 짙은 초록 바닥, 높은 나무 밀도, 나무 그늘 느낌의 풍경과 오두막.
- 능선: 밝은 돌빛 바닥, 큰 바위, 드문 나무, 능선 난간, 열린 전망.
- 마지막 1,600 좌표부터 정상 접근 방향을 부드럽게 안내한다. 정상 전 850 좌표는 경사를 낮추고 최종적으로 평탄해진다.
- 정상석과 루티 라임색 깃발이 있는 정상에 실제 도착하면 이동·시간·발소리가 멈춘다. 사진은 계속 찍을 수 있다.
- 도착 연출 후 계속 산행할지 선택한다. 계속 산행하면 거리·시간·사진·경로를 유지하고 다음 9,000 구간으로 이어진다. 높이도 연속되며 숲/능선 갈림길이 반복된다.
- 기록 마치기 또는 종료로 기록을 확인한다. 방문한 정상 횟수를 루트명에 남긴다. 정상 전에 종료하면 정상 도착이라고 표시하지 않는다.
- 모바일의 기존 작은 HUD 크기를 유지하며 기록 패널 우측에 남은 거리를 표시한다.

## 구현 및 검증

- `dist/trail-world.js`: 연속 반복 코스, 실제 좌표별 환경, 지형 높이와 합류 경로, 정상까지 거리.
- `dist/app.js`: 환경 렌더링, 경로 선택 이동, 정상 도착 상태, 기록/재시작 흐름.
- `tests/trail-world.test.cjs`: 모든 분기의 환경 차이와 합류, 지형 상승·정상 평탄화, 잔여 거리, 좌우 경로 모두 정상 도달 시뮬레이션.

검토용 ChatGPT 주소에서 먼저 확인한다. Cloudflare 공개 사이트 반영은 별도 요청 시 수행한다.

브라우저 확인: 일반 산행으로 약 1분 19초 후 정상 도착, 도착 시 이동/시간 정지, 정상 사진 촬영, 결과에 정상 도착 루트명 표시 및 재시작 초기화를 확인했다. 경로별 동일 지점과 모바일 정상 상태는 배포에서 제외한 임시 검증 화면으로 비교했다.

## 연속 산행 및 렌더링 개선 (2026-11-05)

- 인칭 선택은 사진 담기·종료 바로 위 중앙에 배치한다. 자연 소리와 속도는 그 아래에서 조정한다.
- 지형의 규칙적인 격자를 불규칙한 면으로 바꾸고 나무·바위의 면 명암, 그림자, 길가 풀, 거리 안개와 구름을 추가했다. 화면 해상도 배율 상한은 2다.
- 브라우저에서 정상 → 계속 산행 → 두 번째 정상 → 기록 마치기 및 재시작을 확인했다. 거리·시간·사진이 유지되고 결과에 정상 2회 도착이 표시된다. 320×568 모바일에서도 선택 카드와 하단 버튼이 겹치지 않는 것을 확인했다.
