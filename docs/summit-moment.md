# 정상 도착 기념사진 연출

- 사용자가 제공한 `Frame.png`를 `dist/assets/routee-summit-art.png`로 넣었다. 짙은 바탕의 직사각 깃발에 원본 그래픽을 사용하고, 민트·라임 테두리와 가벼운 흔들림을 추가했다.
- 정상 경계에 닿으면 약 5.4초 동안 3인칭 전환 → 정상석 옆으로 130 월드 단위 걷기 → 카메라를 향해 돌아 휴대폰 올리기 → 프레임/플래시 순서로 진행한다.
- 걸은 거리는 기존 거리·시간·경로에 이어서 기록한다. 정상 방문 횟수와 촬영 사진은 보존한다. 플래시 순간의 정상석·깃발·3인칭 캐릭터를 3:4 사진으로 자동 저장한다. 기존 사진이 5장 이하이면 한 장을 추가하므로 총 최대 6장이 될 수 있다. 이미 6장이면 추가하지 않는다.
- 연출 종료 후 기존 계속 산행/기록 마치기 선택지를 보여준다. 계속 산행하면 기존 시점을 복원하고 다음 코스로 이어간다.
- 줄인 모션 환경에서는 걷기·플래시 없이 짧은 정적 포즈를 보여준다. 숨긴 탭에서는 연출 시간이 진행되지 않는다.
- `dist/trail-summit.js`는 걷기·포즈·셔터·종료 타이밍을 계산하며 `tests/trail-summit.test.cjs`로 단계와 줄인 모션을 확인한다.

자동 사진은 비동기 JPEG 저장으로 처리하고, 촬영 지점을 경로에 남긴다. 기록 완료는 저장 중인 정상 사진이 준비된 다음 진행한다. 재시작 시 자동 사진의 임시 URL도 해제한다.

정상석과 깃발은 실제 정상 위치에서 약 88m 전부터 점차 나타나고, 가까워질수록 원근에 따라 커진다. 앞쪽 나무가 정상석을 가릴 수 있도록 깊이 순서대로 그린다. 정상까지 지형이 부족하지 않게 가시 거리를 연장한다. 산행을 이어가면 이전 정상석은 다음 코스에 남기지 않는다. 현재 정상 뒤 250 단위를 넘는 구조물과 다음 코스의 안내 표지는 산행을 이어가기 전까지 그리지 않는다. 5장에 보너스 사진이 더해지면 수량은 5 + 1로 표시한다.
